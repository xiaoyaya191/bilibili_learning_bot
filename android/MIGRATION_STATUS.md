## 安全边界

- 完整备份不导出 API Key、B 站 Cookie 或 Keystore 密文。
- 恢复完整备份不会覆盖现有 API Key 和 B 站登录凭据。
- B 站发布、弹幕和审核动作必须由用户确认后执行。
- 长视频分析结果只有在视频身份、请求身份和全部分段均一致时才写入 Room。
- 全局界面文案与资源已执行 Emoji 扫描，不使用 Emoji。
