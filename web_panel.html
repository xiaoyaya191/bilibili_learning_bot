MCP 服务
让其他 AI Agent 直接调用本项目的学习与知识能力。




什么是 MCP
MCP（Model Context Protocol）让其他 AI Agent（Claude Desktop / Cursor / Trae 等）直接调用本项目能力：搜B站视频、提取视频文案素材、生成口播稿、查询/搜索/导出知识库。


接入方式


或在项目根目录运行 run_mcp.bat。


{
  "mcpServers": {
    "bili-learn": {
      "command": "run_mcp.bat 或 python 绝对路径",
      "args": ["-m", "mcp_server"],
      "cwd": "项目安装目录"
    }
  }
}
